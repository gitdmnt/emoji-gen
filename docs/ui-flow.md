# 画面の導線

## 手本
- Figma の右パネル: Fill、Stroke、Effects がそれぞれ一覧になり、行ごとに目のアイコン、色見本、不透明度、合成モードを持つ。選んだ行の詳細はその下に開く。
- Photoshop のレイヤーパネル: 上が手前の一覧、ドラッグで並べ替え、目で表示切り替え、合成モードと不透明度は選んだレイヤーに対して一か所で変える。背景は一番下に固定。
- 絵文字メーカー（emoji-gen.ninja など）: 文字入力、フォント、色、保存が一画面に縦に並び、結果は常に見えている。凝った効果は持たない。

## 評価基準
1. 操作の順序: 文字、フォント、見た目、配置、確認、保存の順に上から並び、戻らずに進める。
2. よく使う操作までの手数: 見た目を一気に決める操作（プリセット）が1クリック。細かい調整は、行を選ぶ1クリックの先に置く。
3. 今の状態が一目で分かる: 重なり順、表示のオンオフ、不透明度や合成方法の変更が、詳細を開かずに一覧の行で分かる。
4. プレビューとの距離: どこを操作していても、出力とチャット上の見え方が画面から外れない。

## 構成
- 左の列に手順 1 text、2 font、3 layers、4 layout を上から並べる。
- 右の列（スクロールしても上に貼り付く）に 5 preview と 6 save を置く。幅が狭い画面では右の列を先頭に回す。
- 3 layers は上から、プリセット（利用者の文字で描いた縮小見本）、追加と並べ替えの道具、レイヤー一覧（上が手前、一番下に背景）、選んだレイヤーの設定、の順。一覧の行は目のアイコン、色見本（縁取りは輪、影はぼかし）、種類、既定から変えた値（太さ、合成方法、不透明度）だけを出す。
- 5 preview は 256px の出力と、明るい背景と暗い背景の上にインラインの大きさ（22px）と大きめの表示（48px）を並べた2行だけにする。
