# 画面の導線

## 手本
- Figma の右パネル: Fill、Stroke、Effects がそれぞれ一覧になり、行ごとに目のアイコン、色見本、不透明度、合成モードを持つ。選んだ行の詳細はその下に開く。
- Photoshop のレイヤーパネル: 上が手前の一覧、ドラッグで並べ替え、目で表示切り替え、合成モードと不透明度は選んだレイヤーに対して一か所で変える。背景は一番下に固定。
- 絵文字メーカー（emoji-gen.ninja など）: 文字入力、フォント、色、保存が一画面に縦に並び、結果は常に見えている。凝った効果は持たない。

## 評価基準
1. 操作の順序: 文字、フォント、見た目、配置、確認、保存の順に上から並び、戻らずに進める。
2. よく使う操作までの手数: 見た目を一気に決める操作（プリセット）が1クリック。細かい調整は、行を選ぶ1クリックの先に置く。
3. 今の状態が一目で分かる: 重なり順、表示のオンオフ、不透明度や合成方法の変更が、詳細を開かずに一覧の行で分かる。
4. プレビューとの距離: どこを操作していても、出力とチャット上の見え方が画面から外れない。

## 構成
- 左の列に手順 1 text、2 font、3 layers、4 layout を上から並べる。
- 右の列（スクロールしても上に貼り付く）に 5 preview と 6 save を置く。幅が狭い画面では右の列を先頭に回す。
- 3 layers は上から、プリセット（利用者の文字で描いた縮小見本）、追加と並べ替えの道具、レイヤー一覧、選んだレイヤーの設定、の順。一覧の行は適用順の番号、目のアイコン、色見本（縁取りは輪、影はぼかし）、種類、既定から変えた値（太さ、合成方法、不透明度）だけを出す。
- 5 preview は 256px の出力と、明るい背景と暗い背景のそれぞれに、チャットでの3つの大きさを並べる。単体で送ったとき（32px）、文中に混ぜたとき（22px、前後に短い文）、リアクション（16px、小さなピルの枠）。

## レイヤーの意味
- 一覧の上から順に適用する。行の番号が適用順で、一番下の背景は最後に敷く。
- 形は文字から始まる。塗りはその時点の形全体を塗る。外側の縁取りはその時点の形の外に輪を足し、輪も形の一部になる（後の塗りや縁取りは輪を含んだ形にかかる）。内側の縁取りは形の内側に描き、形は変えない。中央の縁取りは半分ずつ。
- 影はその時点の形から落とし、それまでの結果の後ろに置く。影は形に含めない。後の塗りが影まで塗り潰したり、後の縁取りがぼけた影の輪郭をなぞったりするのは不自然なため。
- 合成方法と不透明度は、そのレイヤーをそれまでの結果に重ねるときに効く（影は先に置いた影に重ねるときに効く）。
- 追加と複製は選んだ行の次に入る。
- 例: 白の塗り、黒の縁取りの順なら黒縁の白文字。黒の縁取り、白の塗りの順なら縁取りの部分まで白い太った文字。

## 金属
- 環境を映した明暗のバンドを塗りの向きに沿って読む: 上は明るい空、中ほどのすぐ上がいちばん明るく、急な地平線で暗い地面に落ち、下端に照り返し。
- 縁は丸いベベル（面取り）として高さを持たせ、傾いた面は環境の別の位置を映す。左上からの光で上と左の縁が明るく、下と右の縁が暗くなり、鏡面反射の細い筋が出る。
- 明るい側は黄白へ、暗い側は赤茶へ色相をずらす（金なら黄色から茶色）。
- 手本: Photoshop Essentials の金文字（グラデーションオーバーレイの反射型とベベルとエンボス、光沢輪郭）、Envato Tuts+ のクロム文字（空、地平線、地面のグラデーションとベベル）。
